Declared values (multiples of 4). Existing project uses these exact values throughout components.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | EQ bar gaps (3px bar + 1px visual gap), icon padding |
| sm | 8px | Button inner padding, tight element gaps |

| lg | 24px | Now-playing bar side padding, section inner gaps |
| xl | 32px | Section padding adjustments |
| 2xl | 48px | — |
| 3xl | 64px | — |

Exceptions:
- Now-playing bar height: not fixed, content-driven — `padding: 12px 28px` (12px vertical = 3 × 4px grid; ~2px tighter than the original demo bar, visually near-identical)

- Video poster play button: 64px × 64px centered circle — large enough for thumb tap
- Gallery grid gap: 12px (matches existing `GallerySection.astro` — do NOT change)

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000` (`--color-bg`) | Page background, now-playing bar base, lightbox overlay |
| Secondary (30%) | `#070707` (`--color-bg-raised`) | Track row hover surface, video card background, lightbox toolbar |
| Accent (10%) | `#f3a9bd` (`--color-accent`) | Reserved — see list below |
| Accent hover | `#ffc0d0` (`--color-accent-hover`) | Hover state for accent-coloured interactive elements |
| Destructive | not applicable | No destructive actions in Phase 2 |

**Accent (`#f3a9bd`) is reserved exclusively for:**
1. EQ animation bars in the now-playing bar (`np-bar`)
2. Now-playing bar top border (`border-top: 1px solid rgba(243,169,189,0.4)`)
3. "▶ слушать" / play indicator text on track rows (existing `.track-play`)
4. Video play button circle border and play icon
5. Lightbox arrow buttons (border or icon color on hover)
6. Active/playing track row left indicator (3px left border on the currently playing `.track` row)

Accent is NOT used on: body text, track titles, track numbers, duration text, video titles, gallery captions, or any non-interactive surface.

**Additional color tokens in use:**
- `--color-text` (`#f2f0ee`) — primary text (track titles, now-playing track name, video titles)
- `--color-text-muted` (`#bdb9b4`) — secondary text (× close button, inactive nav-style controls)
- `--color-text-subtle` (`#9a9691`) — tertiary labels ("сейчас играет", loading state)
- `--color-text-dim` (`#7d7974`) — quaternary (duration, track index, lightbox counter)
- `--color-text-dimmer` (`#5f5b56`) — track numbers (existing; keep as-is)
- `--color-border` (`rgba(255,255,255,0.08)`) — track list row separators (keep as-is)
- Now-playing bar background: `rgba(6,6,6,0.92)` with `backdrop-filter: blur(16px)` — matches existing demo bar

## Component Inventory

### C-01: AudioPlayer Island (`src/components/AudioPlayer.astro`, `client:idle`)

Replaces the throwaway `demo-player.js` IIFE and `<script is:inline>` block in `TracksSection.astro`.

**Now-playing bar layout (fixed bottom, full width):**
```
[ EQ bars ] [ track label / title ] [ spacer ] [ track index ] [ ⏸/▶ ] [ → next ] [ × ]
```
- Bar padding: `12px 28px` (12px vertical on the 4px grid)
- EQ bars: 4 animated pink bars, `@keyframes eq` (already in global.css), animate only when playing, pause when audio is paused
- Track label: 12px Golos Text, `--color-text-subtle`, text "сейчас играет"
- Track title: 18px Prata, `--color-text`
- Track index: 13px monospace, `--color-text-dim`, format "трек 02 / 06"
- Play/pause button: ▶ / ⏸ Unicode, 20px, `--color-text-muted`, 44px tap target, `aria-label="Воспроизвести"` / `aria-label="Пауза"`
- Next button: "→" Unicode, 20px, `--color-text-muted`, 44px tap target, `aria-label="Следующий трек"`; hidden (opacity: 0, pointer-events: none) when on last track
- Close button: × Unicode, 20px, `--color-text-muted`, 44px tap target, `aria-label="Закрыть плеер"`; stops playback and hides bar

**Buffering/loading state:**
- EQ bars switch to a slow pulse (opacity 0.3 ↔ 0.7, no height animation) while audio is loading
- Track label changes to "загружается…" (12px, `--color-text-subtle`)
- Play button shows a static ▶ (not ⏸) during buffering — audio is not yet playing

**Active track row visual:**
- Currently playing `.track` row gets a 3px left accent border (`--color-accent`) and background `rgba(243,169,189,0.05)`
- No animation on the row itself — visual only

**Auto-advance behavior (D-07, D-08):**
- On track `ended` event: 1.5s pause, then 0.4s fade-out of current track (volume 1→0 via ramp), then load+play next
- After the last track: stop, hide now-playing bar — no loop
- The fade is achieved via `audio.volume` ramp over 400ms before `src` swap — no Web Audio API needed

**Track list interaction (D-09):**
- Click playing track = pause/resume (toggle from current position)
- Click different track = stops current, loads new src, plays immediately
- Only one `<audio>` element in the DOM; `src` is swapped on track change

### C-02: VideoSection (`src/components/VideoSection.astro` — new, `client:visible`)

New component. Phase 3 will add a share button to each card — design hooks must be in place.

**Section heading:**
- Eyebrow: 12px Golos Text monospace style, 2.5px letter-spacing, uppercase, `--color-accent`, text "клипы"
- Title: clamp(32px, 5vw, 62px) Prata weight 400, `--color-text`, e.g. "На экране" (copywriting locked below)

**Clip card layout (carousel or grid — see D-14):**
- Each card: aspect-ratio 16/9, `border-radius: 8px`, `overflow: hidden`
- Poster image: fills card, `object-fit: cover`
- Overlay gradient: `linear-gradient(to top, rgba(0,0,0,0.7) 0%, transparent 50%)` — always visible, covers bottom third
- Clip title: 13px Golos Text, `--color-text`, bottom-left of card, inside the overlay area, padding `12px 16px`
- Play button: centered circle, 64px × 64px, `border: 2px solid --color-accent`, `background: rgba(0,0,0,0.4)`, `backdrop-filter: blur(4px)`, ▶ symbol 24px `--color-accent`, `aria-label="Смотреть клип"` (or "Воспроизвести {clip title}")
- On hover: play button scales to 1.08 over 0.25s; poster image scales to 1.02 over 0.5s (same scale transform as `.gallery-item:hover`)

**Playback state (D-15):**
- Click on poster or play button: show native `<video controls>` in-place; `playsinline` attribute set; poster image hidden
- `autoplay` attribute NEVER set
- Video element: `width: 100%; height: 100%; object-fit: cover;` within the card bounds
- On iOS: `playsinline` prevents forced fullscreen (critical for VID-02)

**Phase 3 share hook (D-16):**
- Each card wrapper gets `data-clip-url` and `data-clip-title` attributes — Phase 3 reads these
- Reserve 44px bottom-right corner of each card for a future share button (do not place any content there)
- Share button zone: `position: absolute; bottom: 12px; right: 12px; width: 44px; height: 44px;` — Phase 3 fills this

**Carousel vs. grid (D-14 — Claude's recommendation):**
Use a **horizontal scroll carousel** on mobile (≤860px), **3-column grid** on desktop. Rationale: matches user's "удобно увидеть видео" intuition while keeping desktop layout clean. Carousel snaps to card boundaries (`scroll-snap-type: x mandatory`). Show 1 card at a time on mobile, all cards on desktop. No JS carousel library — pure CSS scroll snap.

### C-03: Lightbox enhancement to GallerySection (`src/components/GallerySection.astro` modified + PhotoSwipe 5)

**PhotoSwipe 5 integration approach:**
- Import PhotoSwipe via `import PhotoSwipe from 'photoswipe'` in a `<script>` block within GallerySection
- Add `data-pswp-src`, `data-pswp-width`, `data-pswp-height` attributes to each `.gallery-item`
- Wrap each image in an `<a>` tag pointing to the full-res src (PhotoSwipe 5 expects anchor elements)
- Initialize with `client:visible` island or a deferred `<script>` that runs after DOM ready

**PhotoSwipe theming (dark/pink):**
```css
--pswp-bg: #000;
--pswp-icon-color: #f2f0ee;
--pswp-icon-color-secondary: #9a9691;
--pswp-error-text-color: #f3a9bd;
```
All PhotoSwipe CSS variables overridden in a `<style is:global>` block to match the established palette.

**Counter display:**
- Format: "3 / 12" — PhotoSwipe 5 exposes this via its `ui.counterEl`; use default counter plugin
- Always visible during lightbox open
- 13px monospace, `--color-text-dim`

**Caption (D-18):**
- Gallery collection schema gains optional `caption: z.string().optional()` field in `content.config.ts`
- Caption shown only when `photo.data.caption` exists — passed via `data-pswp-caption` attribute
- Caption text: 13px Golos Text, `--color-text-muted`, displayed in PhotoSwipe caption slot below image

**Close interactions:**
- × button (PhotoSwipe native, re-styled to match icon-btn pattern)
- Click outside image (PhotoSwipe `closingAnimationType: 'zoom'` or tap-outside default)
- Escape key (PhotoSwipe native)

**Navigation:**
- Arrow buttons: PhotoSwipe native, re-styled; `--color-accent` on hover
- Keyboard left/right: PhotoSwipe native
- Mobile swipe: PhotoSwipe native (touch-enabled by default)

## Interaction State Summary

| Component | States |
|-----------|--------|
| Track row | default → hover (accent bg tint + indent) → playing (left accent border + "играет" label) |
| Now-playing bar | hidden → loading (pulse EQ + "загружается…") → playing (animated EQ + "сейчас играет") → paused (static EQ + "на паузе") |
| Now-playing ⏸/▶ button | playing ↔ paused toggle |
| Now-playing → next button | visible (not last track) ↔ hidden (last track) |

| Gallery item | default → hover (scale 1.015, existing) → lightbox open |

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Audio controls keyboard accessible | Now-playing bar buttons are `<button>` elements; tab order: ⏸/▶ → next → × |
| Audio control aria-labels | Play button `aria-label="Воспроизвести"`, pause `aria-label="Пауза"`, next `aria-label="Следующий трек"`, close `aria-label="Закрыть плеер"` |
| Video play button aria-label | 64px play button `aria-label="Смотреть клип"` (or "Воспроизвести {clip title}") — icon-only button needs accessible name |
| Lightbox keyboard navigation | PhotoSwipe 5 handles Escape, left/right arrows natively |
| Lightbox ARIA | PhotoSwipe 5 sets `role="dialog"` and `aria-modal="true"` on the lightbox container; close `aria-label="Закрыть"`, prev/next labelled |
| Video controls accessible | Native `<video controls>` provides accessible controls; `playsinline` does not affect accessibility |
| Video error has solution path | Error copy "Видео временно недоступно. Попробуйте обновить страницу." gives the user a recovery action |
| EQ animation respects motion preference | `@media (prefers-reduced-motion: reduce)` stops `@keyframes eq` animation; EQ bars remain visible at static height |
| Touch targets | All now-playing controls ≥ 44px tap area; video play button 64px |
| Image alt text | Already defined in gallery collection `alt` field; passed through to PhotoSwipe |
