| Vercel Blob CDN → public internet | Media URLs are public-by-design; the site itself is noindex pre-launch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Public Blob URLs expose pre-launch media before band approval | accept | URLs are unguessable (store-id hashed); site is noindex (FND-07); pre-launch demo audience is trusted. Public access is the intended end state. No PII in media. |
| T-02-02 | Tampering / secret leak | BLOB_READ_WRITE_TOKEN committed or exposed client-side | mitigate | Token stays in .env.local (gitignored) / Vercel runtime only; never PUBLIC_ prefixed; used at upload time only, never in built site (RESEARCH Security Domain). |
| T-02-SC | Tampering | npm package installs (vercel CLI via npx) | accept | No new package added to package.json in this plan; `vercel` CLI resolved via `npx vercel@latest` is the official Vercel CLI ([OK] in RESEARCH Package Legitimacy Audit). |

No SSRF, injection, auth, or serverless surface exists in this plan (data files + CDN upload only).
</threat_model>
