## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/book (Vercel serverless) | Untrusted, unauthenticated public form input crosses into the server function |
| /api/book → Telegram Bot API | Server uses the secret bot token to call api.telegram.org over HTTPS |
| /api/book → Resend API (gated) | Server uses the Resend API key over HTTPS only when EMAIL_ENABLED=true |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03B-01 | Information Disclosure | TELEGRAM_BOT_TOKEN | mitigate | Token read only from `process.env.TELEGRAM_BOT_TOKEN` in server-only `src/pages/api/book.ts`; no PUBLIC_ prefix; never logged; Task 5 verification greps `dist/` to confirm absence from client bundle |
