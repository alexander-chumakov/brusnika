|----------|-------------|
| browser → Vercel Blob CDN | `<video>` fetches clip + poster over HTTPS; Range requests cross this boundary; public read, no auth |
| videos JSON (build-time) → component (client) | CDN URLs baked into static HTML via getCollection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-08 | Information Disclosure | Mixed content (http video on https page) | mitigate | videoUrl/posterUrl are `https://…public.blob.vercel-storage.com/…` only (Blob is HTTPS); no http:// permitted in video JSON. |
| T-02-09 | Denial of Service | preload of 4 large clips on load saturates the connection | mitigate | `preload="none"` on every `<video>`; clips fetch only on user click (also satisfies "no autoplay"). |
| T-02-10 | Information Disclosure | Pre-launch clips exposed via public CDN before band approval | accept | Same disposition as T-02-01: noindex site, unguessable URLs, trusted pre-launch audience; public is the intended end state. |

No serverless, auth, secrets, or persisted user input in this plan. The Phase 3 share surface is reserved only (no `navigator.share` code here).
</threat_model>
