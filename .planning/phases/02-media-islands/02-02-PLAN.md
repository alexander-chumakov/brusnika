<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Vercel Blob CDN | `<audio>` fetches media over HTTPS; Range requests cross this boundary; no auth, public read |
| track JSON (build-time) → island (client) | CDN URL flows via data-audio-url attribute baked into static HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Information Disclosure | Mixed content / HTTP CDN URL on an HTTPS page | mitigate | data-audio-url values are `https://…public.blob.vercel-storage.com/…` (Blob is HTTPS-only); no http:// URLs permitted in track JSON. |
| T-02-04 | Denial of Service | Multiple simultaneous audio streams from one-element-per-track race | mitigate | Single `<audio>` element + src swap (Pattern 2) structurally prevents concurrent streams; only one track plays at a time (AUD-03). |
| T-02-05 | Tampering | Client-side script could be told to load an arbitrary URL | accept | URLs come only from build-time-validated track JSON (Zod), not user input; no user-supplied URL surface in this phase. |

No serverless endpoint, auth, secrets, or persisted user input in this plan. Audio is client-only over a public CDN.
</threat_model>
