## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitor browser → Vercel CDN | All responses are static prerendered HTML/assets; no untrusted input is accepted or processed in this plan |
| Build env → client bundle | `NOINDEX` env var is read at build time and inlined into HTML; it is non-secret configuration |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `import.meta.env.NOINDEX` inlined into static HTML | accept | NOINDEX is non-secret build config (a boolean toggle); no secret value is exposed. No real secrets exist in Phase 1. |
| T-01-02 | Information Disclosure | Premature public indexing of the private band-review demo | mitigate | Env-gated `<meta name="robots" content="noindex, nofollow">` rendered when NOINDEX=true, redundant with Vercel's auto `X-Robots-Tag: noindex` on Preview deployments (FND-07) |
| T-01-SC | Tampering | npm package installs (astro, @astrojs/vercel, @fontsource/*, photoswipe) | mitigate | All five packages verified against official source repos in RESEARCH § "Package Legitimacy Audit" (all `Approved`, no postinstall scripts). No `[ASSUMED]`/`[SUS]`/`[SLOP]` packages — no blocking checkpoint required. |
</threat_model>
